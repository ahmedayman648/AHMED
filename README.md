# دردشة

## التشغيل على جهازك
    npm install
    npm start
ثم افتح http://localhost:3000

## عشان شخص من دولة تانية يستخدمه
السيرفر لازم يكون متاح على الإنترنت. فيه طريقتين:

1) تجربة سريعة (جهازك لازم يفضل شغال): شغّل السيرفر ثم افتح نفق مؤقت بأداة زي ngrok أو Cloudflare Tunnel
   مثال ngrok:  ngrok http 3000   ← هيديك رابط https تبعته للشخص التاني.

2) نشر دائم: ارفع المشروع على سيرفر (VPS أو خدمة استضافة Node.js).
   - ضروري تحط البيانات على قرص دائم: اضبط المتغير DATA_DIR على مسار القرص (بيتخزن فيه data.json وفولدر uploads).
   - لازم HTTPS (التسجيل الصوتي بالميكروفون مش بيشتغل من غير HTTPS ما عدا localhost).
   - أمر التشغيل: npm start، والبورت بيتاخد من المتغير PORT.

متغيرات اختيارية: PORT، DATA_DIR، MAX_UPLOAD_MB (الافتراضي 25).
